📌 Project Summary
This project performs text preprocessing on a paragraph using NLTK and extracts features using Scikit-learn. It includes:

Cleaning the text (removing punctuation, converting to lowercase, removing stopwords, lemmatization).

Tokenizing the text into sentences and words.

Creating:

Bag of Words (BoW): Represents text as word frequency.

TF-IDF Matrix: Highlights important words based on their frequency across the text.

These techniques are commonly used in Natural Language Processing (NLP) for preparing text data for machine learning models.
